# Soupers · Ateliers du Champ Libre

Web app installable (iPhone) pour planifier les soupers, gérer l'inventaire du congélateur et partager des recettes entre amis.

- `web/` — l'application (React + Vite). Sans fichier `.env`, elle démarre en mode démo.
- `supabase/migrations/` — base de données et règles de sécurité.
- `supabase/functions/ai/` — fonction IA (Claude).
- `supabase/tests/` — tests de sécurité.
- `.github/workflows/` — déploiement automatique, maintien en activité, mises à jour de sécurité.
- `docs/REVUE.md` — revue sécurité, propriété intellectuelle et coûts.
- `docs/MISE-EN-LIGNE.md` — étapes de mise en ligne.
- `docs/ITERATIONS.md` — comment faire évoluer l'app.
